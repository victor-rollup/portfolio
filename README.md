## 🚀 Sobre el Proyecto

Este proyecto alberga la web personal de **Víctor Eduardo León Carreño**, Frontend Engineer Senior con más de 6 años de experiencia en desarrollo web, optimización de bases de datos y arquitectura de sistemas.

### 🛠️ Tech Stack & Arquitectura

- **Framework:** Vue 3 (Composition API `<script setup lang="ts">`).
- **Language:** TypeScript.
- **Routing:** Vue Router (Navegación por secciones y lazy loading).
- **Estilos:** CSS nativo con arquitectura modular y metodología **BEM**.
- **Build Tool:** Vite con TypeScript Native Bridge.
- **Package Manager:** `pnpm`.
- **Despliegue:** Vercel.

## 💻 Desarrollo Local

### Requisitos previos

- **Node.js:** `^22.18.0` o `>=24.12.0`
- **pnpm:** Recomendado como gestor de paquetes.

### Instalación

```bash
# Clona el repositorio
git clone https://github.com/victor-rollup/portfolio.git

# Entra al directorio
cd portfolio

# Instala las dependencias
pnpm install
```

### Comandos disponibles

```bash
# Ejecutar en entorno de desarrollo con Hot-Reload
pnpm client

# Verificación de tipos TypeScript
pnpm type-check

# Compilar para producción (con verificación de tipos previa)
pnpm build

# Previsualizar el build de producción localmente
pnpm preview
```
